วัตถุประสงค์

เมื่อจบ Workshop นี้ นักศึกษาจะสามารถ

  1. เขียนเอกสารภาษาไทยด้วยแพ็กเกจ thaispec และคอมไพล์ด้วย XeLaTeX ได้
  2. เลือกฟอนต์ภาษาไทยด้วยตัวเลือก thaifont ได้
  3. สร้างคำสั่งใหม่ด้วย \newcommand ทั้งแบบไม่มีและมีอาร์กิวเมนต์ และเขียนทับคำสั่งเดิมด้วย \renewcommand ได้
  4. สร้างสภาพแวดล้อมใหม่ด้วย \newenvironment รวมถึงอาร์กิวเมนต์ที่มีค่าเริ่มต้นได้
  5. แบ่งเอกสารเป็นหลายไฟล์ด้วย \input และ \include และบอกความแตกต่างของทั้งสองคำสั่งได้

ไฟล์ที่ได้รับ

ดาวน์โหลด thai_macros.zip แล้วแตกไฟล์ไว้ในที่ที่หาง่าย จะได้โฟลเดอร์ thai_macros ดังนี้

thai_macros/
├── doc.pdf            ชิ้นงานต้นแบบ (3 หน้า)
├── warmup.tex         ไฟล์สั้น ๆ สำหรับ Part A
├── main.tex           ไฟล์เริ่มต้นสำหรับ Part B
├── content.txt        เนื้อหาทั้งหมดของ Part B ไม่ต้องพิมพ์ใหม่
└── Laksaman.fontspec  บอก XeLaTeX ว่าไฟล์ฟอนต์ Laksaman อยู่ที่ใด (ห้ามลบ)

ดูไฟล์แยกทีละไฟล์ได้ที่ warmup.tex, main.tex, content.txt, Laksaman.fontspec

Windows

PS> xelatex --version

$ xelatex --version

Linux

$ xelatex --version

Part A

อุ่นเครื่อง

ประมาณ 40 นาที

ใช้ไฟล์ warmup.tex (ประกาศเวลาเปิดห้องสมุด) ทำทีละข้อ

  1. A0 คอมไพล์ warmup.tex ตามที่ได้รับด้วย pdflatex warmup.tex 
    ! LaTeX Error: Unicode character ห (U+0E2B)
               not set up for use with LaTeX.
    พิมพ์ X แล้วกด Enter เพื่อหยุด จากนั้นลองคอมไพล์ด้วย xelatex warmup.tex แล้วเปิด PDF และเปิดไฟล์ warmup.log หาคำว่า Missing character

    XeLaTeX หยุดเพราะข้อผิดพลาดหรือไม่ ข้อความภาษาไทยใน PDF เป็นอย่างไร และทำไม

  2. A1 เพิ่ม \usepackage{thaispec} ต่อจาก \documentclass แล้วลองคอมไพล์ด้วย pdflatex อีกครั้ง 
    ! Fatal Package fontspec Error: The fontspec package requires either XeTeX or
(fontspec)                      LuaTeX.
    จากนั้นลองด้วย xelatex warmup.tex

    ถ้าเครื่องไม่มีฟอนต์ TH Sarabun New ข้อความผิดพลาดบอกว่าหาฟอนต์ชื่อใดไม่พบ

  3. A2 ใช้ฟอนต์ Laksaman เปลี่ยนเป็น \usepackage[thaifont=Laksaman]{thaispec} แล้วคอมไพล์ด้วย latexmk 
    $ latexmk -xelatex warmup.tex
    ลองย้ายไฟล์ Laksaman.fontspec ไปไว้ที่อื่นชั่วคราวแล้วคอมไพล์ใหม่ 
    ! Package fontspec Error: 
(fontspec)                The font "Laksaman" cannot be found; this may be
(fontspec)                but usually is not a fontspec bug. Either there is
(fontspec)                a typo in the font name/file, the font is not
    แล้วย้ายไฟล์กลับมาที่เดิม

    ข้อความภาษาอังกฤษบรรทัดแรกใช้ฟอนต์เดียวกับภาษาไทยหรือไม่

  4. A3 ลองครอบคำว่า ห้องสมุด ด้วย \textbf{...} แล้วครอบคำว่า ค่าปรับ ด้วย \textit{...}

    ตัวเอียงภาษาไทยอ่านง่ายหรือไม่ ถ้าต้องเน้นข้อความภาษาไทย ควรใช้รูปแบบใด

  5. A4 คำสั่งไม่มีอาร์กิวเมนต์ เพิ่มในส่วนนำ 
    \newcommand{\rmutt}{มหาวิทยาลัยเทคโนโลยีราชมงคลธัญบุรี}
    แล้วแทนชื่อมหาวิทยาลัยในเนื้อความด้วย ของ\rmutt{}เปิดบริการ จากนั้นลองลบ {} ออกให้เป็น ของ\rmuttเปิดบริการ 
    ! Undefined control sequence.
l.13 ห้องสมุดของ\rmuttเปิดบริการทุกวัน

    ทำไม LaTeX จึงคิดว่า \rmuttเปิดบริการทุกวัน เป็นคำสั่งเดียว และ {} ช่วยได้อย่างไร

  6. A5 คำสั่งมีอาร์กิวเมนต์ เพิ่ม \newcommand{\baht}[1]{#1~บาท} แล้วเปลี่ยน วันละ 5 บาท เป็น วันละ \baht{5}

    #1 ถูกแทนด้วยอะไร และ ~ ช่วยอะไรเมื่อตัวเลขอยู่ท้ายบรรทัด

  7. A6 เขียนทับคำสั่งเดิม เพิ่ม \renewcommand{\emph}[1]{\textbf{#1}} ในส่วนนำ แล้วใช้ \emph{...} เน้นคำในเนื้อความ จากนั้นเพิ่ม \begin{abstract} ... \end{abstract} สั้น ๆ ต่อจาก \begin{document} และลองเปลี่ยนหัวบทคัดย่อด้วย \renewcommand{\abstractname}{บทคัดย่อ} สองตำแหน่ง ได้แก่ ในส่วนนำ และต่อจาก \begin{document}

    ตำแหน่งใดได้ผล (thaispec ตั้งชื่อหัวข้อต่าง ๆ ใหม่ตอนเริ่มเอกสาร จึงทับค่าที่ตั้งไว้ในส่วนนำ)

  8. A7 สภาพแวดล้อมใหม่ สร้างกรอบข้อความตามแบบในสไลด์ แต่ให้มีหัวกรอบเป็นอาร์กิวเมนต์ที่ไม่บังคับ 
    \newenvironment{note}[1][ข้อสังเกต]
  {\begin{center}
   \begin{tabular}{|p{0.9\textwidth}|}
   \hline
   \textbf{#1}\\}
  {\\
   \hline
   \end{tabular}
   \end{center}}
    ลองใช้ทั้ง \begin{note} และ \begin{note}[โปรดทราบ]

    ค่าในวงเล็บเหลี่ยม [ข้อสังเกต] ของบรรทัดแรกใช้เมื่อใด

  9. A8 แบ่งไฟล์ ย้ายย่อหน้าภาษาไทยทั้งย่อหน้าไปไว้ในไฟล์ใหม่ชื่อ hours.tex แล้วเขียน \input{hours} แทนที่ คอมไพล์ จากนั้นเปลี่ยนเป็น \include{hours}

    \include ทำอะไรเพิ่มจาก \input และเหมาะกับเอกสารแบบใด

    ทำให้ผิดโดยตั้งใจ ทำทีละข้อแล้วแก้กลับ
    1. เพิ่ม \newcommand{\emph}[1]{\textbf{#1}} (ใช้ \newcommand แทน \renewcommand) 
      ! LaTeX Error: Command \emph already defined.
               Or name \end... illegal, see p.192 of the manual.
    2. ลบ [1] ออกจาก \newcommand{\baht}[1]{#1~บาท} 
      ! Illegal parameter number in definition of \baht.
<to be read again> 
                   1
l.7 \newcommand{\baht}{#1~บาท}
    3. สะกดชื่อไฟล์ผิดเป็น \input{hourz} 
      ! LaTeX Error: File `hourz.tex' not found.
จุดตรวจ ถึงตรงนี้ควรตอบได้ว่า (1) ทำไมเอกสารภาษาไทยต้องใช้ XeLaTeX (2) \newcommand กับ \renewcommand ต่างกันอย่างไร (3) #1 และค่าเริ่มต้นในวงเล็บเหลี่ยมทำงานอย่างไร และ (4) ควรเลือก \input หรือ \include เมื่อใด
Part B

งานหลัก

ประมาณ 50 นาที

สร้างรายงานโครงการธนาคารขยะภาษาไทยให้เหมือน doc.pdf มากที่สุด โดยแบ่งเป็น 3 ไฟล์ ได้แก่ main.tex (ส่วนนำ บทนำ และสรุป) method.tex (วิธีดำเนินงาน) และ results.tex (ผลการดำเนินงาน) เนื้อหาทั้งหมดอยู่ใน content.txt แยกตามไฟล์ไว้แล้ว คอมไพล์เฉพาะไฟล์หลัก

$ latexmk -xelatex main.tex

คำแนะนำ

ส่วนของชิ้นงานสิ่งที่ต้องใช้
ภาษาไทยและขนาดตัวอักษร\documentclass[12pt]{article}, thaispec กับ thaifont=Laksaman
ชื่อมหาวิทยาลัย ชื่อชมรม จำนวนเงิน\newcommand สร้าง \rmutt, \club และ \baht ตามที่ระบุใน content.txt
คำเน้นเป็นตัวหนา\renewcommand ของ \emph
หัวข้อ บทคัดย่อ\renewcommand ของ \abstractname (ระวังตำแหน่ง)
ชื่อเรื่องสองบรรทัด\\ ใน \title
กรอบข้อสังเกต\newenvironment ที่มีอาร์กิวเมนต์ไม่บังคับ
วิธีดำเนินงานและผลการดำเนินงานไฟล์แยก นำเข้าด้วย \input
ตารางtable, tabular, \caption ใต้ตาราง, \label และ \ref
คำใบ้เพิ่มเติม (เปิดดูเมื่อติด)
  • ไฟล์ method.tex และ results.tex ไม่มี \documentclass หรือ \begin{document} มีเฉพาะเนื้อหา
  • ใช้ \input ไม่ใช่ \include เพราะ \include ขึ้นหน้าใหม่ทุกครั้ง ทำให้จำนวนหน้าไม่ตรงกับต้นแบบ
  • ถ้าคำสั่งที่สร้างเองตามด้วยอักษรไทยทันที ให้ใส่ {} ต่อท้าย เช่น \club{}เปิด
  • ใน log อาจมีข้อความ Underfull \hbox หลายบรรทัด เป็นเรื่องปกติของการตัดคำภาษาไทย ไม่ต้องแก้

Part C

ท้าทาย

ไม่บังคับ · ประมาณ 20–30 นาที

ทำเพิ่มในไฟล์ใหม่ ข้อใดก็ได้

  1. C1 สร้างคำสั่ง \amount ที่มีอาร์กิวเมนต์ไม่บังคับเป็นหน่วย ค่าเริ่มต้นคือ กิโลกรัม เช่น \amount{620} ได้ 620 กิโลกรัม และ \amount[คน]{412} ได้ 412 คน

    รูปแบบ \newcommand{\amount}[2][กิโลกรัม]{...} นับอาร์กิวเมนต์ไม่บังคับเป็น #1 หรือ #2

  2. C2 ใช้ตัวเลือก thainum ของ thaispec ให้เลขหัวข้อเป็นเลขไทย
  3. C3 ลองฟอนต์ไทยอื่นที่มากับ TeX Live เช่น Kinnari, Garuda หรือ Norasi โดยสร้างไฟล์ Kinnari.fontspec ตามแบบ Laksaman.fontspec (ดูชื่อไฟล์ฟอนต์ได้ด้วยคำสั่ง kpsewhich Kinnari-Bold.otf)
  4. C4 เปลี่ยนรายงานเป็นคลาส report ให้แต่ละส่วนเป็น \chapter แล้วนำเข้าด้วย \include ลองใส่ \includeonly{results} ในส่วนนำ

    เลขหน้าและเลขบทของส่วนที่ไม่ได้คอมไพล์ยังถูกต้องหรือไม่

ข้อผิดพลาดที่พบบ่อย

อาการสาเหตุและวิธีแก้
! LaTeX Error: Unicode character ... not set up for use with LaTeX. คอมไพล์ภาษาไทยด้วย pdflatex ให้ใช้ xelatex หรือ latexmk -xelatex
! Fatal Package fontspec Error: The fontspec package requires either XeTeX or LuaTeX. มี thaispec แต่คอมไพล์ด้วย pdflatex แก้เหมือนข้อบน

The font "Laksaman" cannot be found ไม่มีไฟล์ Laksaman.fontspec ในโฟลเดอร์เดียวกับไฟล์ .tex
The font "THSarabunNew" cannot be found เครื่องไม่มีฟอนต์ TH Sarabun New ใช้ thaifont=Laksaman แทน
! Undefined control sequence. ที่คำสั่งที่สร้างเอง คำสั่งติดกับอักษรไทยจนชื่อยาวขึ้น ใส่ {} ต่อท้ายคำสั่ง
! LaTeX Error: Command \xxx already defined. ชื่อนี้มีอยู่แล้ว เปลี่ยนชื่อ หรือใช้ \renewcommand ถ้าตั้งใจเขียนทับ

! LaTeX Error: File `xxx.tex' not found. ชื่อไฟล์ใน \input หรือ \include ผิด หรือไฟล์อยู่คนละโฟลเดอร์
